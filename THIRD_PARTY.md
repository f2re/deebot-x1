# Сторонние компоненты

## Bumper

DEEBOT X1 Local не встраивает исходный код Bumper в этот репозиторий. Установщик получает Bumper отдельно из `MVladislav/bumper` и по умолчанию фиксирует стабильный тег `v0.4.1`.

Bumper распространяется отдельно под GPL-3.0. Его лицензия и авторские права определяются upstream-репозиторием.

## Home Assistant

Home Assistant является внешней системой. Этот проект не копирует Home Assistant и не редактирует его внутренние `.storage` registry-файлы.
