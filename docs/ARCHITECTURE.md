# Архитектура

```text
DEEBOT X1
   │
   │ MQTT/TLS + REST через локальный DNS
   ▼
Bumper
   │
   ├── REST :8007
   ├── MQTT/TLS :8883
   └── XMPP :5223 (для совместимости Bumper)
          │
          ▼
существующий Home Assistant
          │
          ├── штатный vacuum UI / Clean by area
          └── опционально DEEBOT PWA :8090
```

## Границы ответственности

**Bumper** эмулирует облачную сторону Ecovacs. **Home Assistant** хранит свою конфигурацию и предоставляет сервисы `vacuum.*`. **DEEBOT PWA** — тонкий локальный прокси/UI; HA-токен остаётся на сервере и не передаётся браузеру.

## Карты

SLAM и навигация остаются в штатной прошивке X1. PWA может архивировать изображения карты, полученные через Home Assistant, но это не является восстановлением внутренней SLAM-базы робота.

## DNS

DNS-переопределение следует применять только к роботу или IoT VLAN. Глобальная переадресация `ecovacs.com` для всей домашней сети нежелательна.

## Обновления

Установка фиксирует стабильный Bumper tag. `install.sh` не меняет уже установленную ревизию. `update.sh --latest` сначала создаёт backup и только затем переходит на последний GitHub release Bumper.
