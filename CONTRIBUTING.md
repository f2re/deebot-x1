# Разработка

Проект намеренно остаётся небольшим: Bumper отвечает за протокол Ecovacs, Home Assistant — за интеграцию умного дома, этот репозиторий — за безопасное развёртывание, локальный DNS, диагностику и опциональную PWA.

## Перед PR

```bash
python3 -m pip install -r dashboard/requirements.txt PyYAML
./scripts/check.sh
```

Если установлен `shellcheck`, скрипт проверит и shell-код. В CI `shellcheck` обязателен.

## Правила изменений

- Не записывать напрямую `.storage` Home Assistant.
- Не коммитить HA-токены, сертификатные ключи, `.install.env`, `.dashboard.env`, карты и диагностические архивы.
- Не переводить установку обратно на плавающий `Bumper main` по умолчанию; стабильная версия должна быть явной.
- Любое изменение DNS должно иметь безопасный откат.
- Команды роботу из веб-интерфейса должны проходить серверную валидацию.
