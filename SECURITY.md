# Безопасность

Не публикуйте в issues/PR:

- Home Assistant Long-Lived Access Token;
- `.dashboard.env` и `.install.env`;
- `certs/*.key`;
- содержимое `/config/.storage` Home Assistant;
- карты помещения, если они раскрывают нежелательную информацию о доме.

`collect-debug.sh` намеренно не включает эти секреты, однако диагностический архив всё равно следует просмотреть перед публикацией.

PWA рассчитана на LAN/VPN. Не публикуйте порт `8090` напрямую в Интернет. Для удалённого доступа используйте VPN либо существующий reverse proxy с TLS и аутентификацией.
